# MindGuild
MindGuild es una aplicación móvil gamificada de estudio colaborativo y competitivo, diseñada para ayudar a estudiantes a prepararse para exámenes reales mediante hábitos de estudio constantes, interacción grupal y validación del conocimiento
La app combina tres pilares:
  Productividad: sesiones Pomodoro, organización y seguimiento.
  Competencia social: rankings, desafíos, modos de juego.
  Aprendizaje real: simulacros, preguntas creadas por usuarios y análisis de rendimiento
