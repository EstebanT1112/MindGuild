# EXPO UI RULES (LITE)

Use these rules ONLY for UI behavior and styling.

---

## DO

* Use ScrollView or FlatList as root container
* Handle safe areas properly
* Use flexbox layouts
* Use Pressable for interactions
* Use expo/vector-icons or similar
* Add basic animations for state changes
* Keep UI mobile-first

---

## DO NOT

* Do NOT use expo-router
* Do NOT use Link
* Do NOT use NativeTabs
* Do NOT define routes inside /app
* Do NOT override project architecture

---

## STYLING

* Prefer StyleSheet or NativeWind (project defined)
* Keep spacing consistent
* Use design-system tokens
* Avoid inline-only styling unless necessary

---

## UX

* Keep interactions simple
* Avoid unnecessary complexity
* Prioritize clarity and responsiveness
